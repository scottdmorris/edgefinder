# Ball Knowledge logo concepts

The exploration sheet preserves three directions: 01 Courtside IQ (basketball/brain),
02 The Playbook, and 03 Court Vision (basketball/eye).

Court Vision was selected on 2026-11-15. Production artwork is hand-built SVG in
`assets/logo-mark.svg`, mirrored in `web/public/logo-mark.svg`, with the lockup in
`assets/logo.svg`. The PNG is a generated concept reference, not a production asset.

Keep Courtside IQ as an alternative for future exploration. Its lower brain lobes
need simplifying before reconsideration. The user also prefers darker themes;
that preference is independent of the logo direction.
